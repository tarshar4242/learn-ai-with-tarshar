## 研究問題

它的系統與評估方式和本研究哪裡相同、哪裡不同？

## 主要發現

使用紀錄含測試期，B正確率最高（未檢定）；模型問卷均分差多未顯著。

## 怎麼用進本研究

分開檢索命中、最終作答、AI回答正確與滿意度。（研讀建議，待老師判斷）

## 限制
