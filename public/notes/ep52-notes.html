2. 為什麼一堂 Power BI 課，要從 Excel 講起

開場四分鐘，老師做了一件不太常見的事：把自己這堂課的主角往後挪。

課名叫「如何讓 AI 協助完成 Power BI」，但他一開口就先把期待值調整掉——Power BI 這一段現在很短，因為寫 DAX、生 .pbip 檔這些事，AI 已經能做完。真正會讓你卡住的，是在那之前。

「今天的課程會聚焦在 Power BI。但是我 Power BI 的部分會講稍微少一點，因為其實現在交給 GPT 幫你寫好，DAX 幫你寫好」
［00:30］開場第一句。整堂的結構就是從這句話長出來的：前 40 分鐘都在講「進 Power BI 之前」，最後 10 分鐘才真的碰到 Power BI。

三個練習，各約 15 分鐘

他自己說「我大概區分成 15 分鐘一個練習」。三段的關係不是並列，是遞進——每一段都在回答同一個問題的不同層次：這件事我下次還要再做一遍嗎？

  • 練習一　巨集、VBA、增益集——「最近很常有人問我說老師什麼時候要用巨集，什麼時候用 VBA，什麼時候用增益集。」這一段就是在回答這個分工問題。
  • 練習二　Power Query——不寫函數、不寫程式，把清理動作變成一份可以重跑的步驟清單。
  • 練習三　用 ChatGPT 操作 Power BI——視覺化與 DAX 函數，交給外掛程式生成。

為什麼要拿「中秋烤肉」當練習資料

他準備的不是乾淨的示範檔，是刻意做壞的資料。理由很實際：真實世界的報表就長這樣，而髒資料會直接讓後面整條路走不通。

🔧
老師這段口述提到「他的髒資料不是說他 key 錯了還是他寫錯了」，意思是：這些不一致不是打錯字，而是不同人、不同時間、不同習慣填進來的合理寫法——所以你沒辦法靠校對解決，只能靠規則統一。
04:00–13:00

3. 巨集：把你剛剛點過的每一步錄下來

這一段的目標只有一個欄位：把折扣欄的六種寫法，統一成一個能拿去算的百分比。

第一步不是錄製，是另存檔案

巨集寫在檔案裡，而一般的 .xlsx 不保存程式碼——你錄完關檔，隔天打開就沒了。所以順序是：先轉檔，再錄製。

⚠️
一定要先另存成 .xlsm（啟用巨集的活頁簿）。老師的原話是「你一定要把你的 Excel 檔先做一個轉檔的動作，通常要 XLSM 檔它比較適合巨集的方式」。路徑是檔案 → 另存新檔 → 檔案類型選「Excel 啟用巨集的活頁簿」。他順手把檔名改成 data_0904，後面整堂都用這個檔。
💡
找不到「開發人員」頁籤是最常見的第一個卡點。開法：檔案 → 選項 → 自訂功能區 → 右側勾選「開發人員」。勾完頁籤才會出現，錄製巨集、Visual Basic、增益集三個按鈕都在那裡。

錄製巨集的六個動作

  1. 到開發人員頁籤，按錄製巨集。
  2. 給巨集一個名稱（老師取「統一折扣率」），並在描述欄寫清楚它做什麼——他寫的是「將混合的折扣格式改成標準格式」。儲存在「這個活頁簿」。
  3. 按確定，Excel 開始錄。從這一刻起你點的每一下都會被記成程式碼，所以不要亂點。
  4. 在資料右側插入一個新欄位，欄名輸入「標準折扣率」。
  5. 在第一格輸入轉換公式，向下填滿，再把整欄設成百分比格式、小數位數 0 位。
  6. 回到開發人員，按停止錄製。

轉換規則：六種寫法怎麼變成一個數字

這張對照表是從課堂畫面上實際跑出來的結果讀出來的（見第 5 章的截圖），也和簡報第 10 頁的「轉換規則範例」一致。

原始「折扣」欄轉成「標準折扣率」規則
5%、10%、0%5%、10%、0%本來就是百分比，原樣保留
0.05、0.1、0.085%、10%、8%小數就是比率，乘 100 顯示成百分比
9折10%「幾折」講的是付幾成，折扣率＝1－0.9
92折8%同上，1－0.92
無、0、空白0%沒有折扣一律歸零，不留空值
🔧
這一步的公式老師沒有自己寫，是丟給 AI 寫的：「這時候其實就可以請 AI 出來了，你就不用浪費時間。比如說我到底要怎麼去統一我的格式，你就貼上這一段。」本頁沒有收錄那段公式的原文——他在課堂上是直接貼進儲存格、沒有把提示詞念出來，逐字稿裡也沒有完整內容，這裡不猜測補寫。
13:00–18:00

4. VBA：讓 AI 把錄下來的碼改成能重複跑的程式

錄製出來的巨集能跑，但很笨。這一章是全堂 AI 用得最直接的一段：複製、貼上、要它改寫。

錄製巨集的問題在於它記的是「你點了哪裡」而不是「你想做什麼」。你多點了一下、資料多了兩列，它就會出錯。老師的處理方式很簡單：把碼整段複製，丟給 ChatGPT，要它改成穩定版本。

  1. 按 ALT ＋ F11 直接進 VBA 編輯器（或從開發人員頁籤點 Visual Basic）。
  2. 從左側找到剛才錄的那支巨集（工具 → 巨集 → 選「統一折扣率」→ 編輯），把整段程式碼全選複製。
  3. 貼給 ChatGPT，請它修正並改寫成更完整、更周延的版本。老師的說法是「就是點的，跟你實際執行的，他可能會有一些問題，所以他會幫你做統一的整理、統一的修正」。
  4. 把 AI 回傳的碼貼回 VBA 編輯器，存檔，按執行。

畫面上讀得到的關鍵段落如下（只抄畫面清楚可見的部分，右側被裁掉或看不清的行不補寫）：

Sub 統一折扣率() Dim ws As Worksheet Dim lastRow As Long Dim targetCol As Long Dim foundCell As Range Set ws = ActiveSheet '找出 H 欄最後一筆資料 lastRow = ws.Cells(ws.Rows.Count, "H").End(xlUp).Row '找找看是否已經有「標準折扣率」 Set foundCell = ws.Rows(1).Find(What:="標準折扣率", LookAt:=xlWhole) If foundCell Is Nothing Then '如果沒有，就在 H 欄右邊新增 I 欄 ws.Columns("I:I").Insert Shift:=xlToRight targetCol = 9 ws.Cells(1, targetCol).Value = "標準折扣率" Else '如果已經存在，就直接使用原本的欄位 targetCol = foundCell.Column '清除舊結果 ws.Range(ws.Cells(2, targetCol), _ ws.Cells(ws.Rows.Count, targetCol)).ClearContents End If
💡
這段 If foundCell Is Nothing Then … Else … 就是簡報第 11 頁講的「重複按下時，不再重複新增欄位，而是重新整理結果」。判斷欄位在不在、在的話清空重算——差別只在這幾行，但它決定了這支工具能不能給別人用。

執行後 Excel 會跳出提示：「折扣率整理完成，共處理 16 筆資料。」老師接著把剛才手動錄的結果整欄刪掉，再按一次 AI 版本，證明它能重跑出一樣的結果。

最後一步：把程式碼藏起來，換成一顆按鈕

他的理由很白話：「我們可能不會想常常看到這個碼。你會說，我常常在這邊會看到這個碼，覺得有點害怕。」所以把它包成按鈕。

  1. 開發人員 → 插入 → 表單控制項的「按鈕」，在工作表上畫出來。
  2. Excel 會問要指定哪一支巨集，選「統一折扣率」，按確定。
  3. 把按鈕文字改成看得懂的名字——老師取的是「一鍵整理折扣率」。
⚠️
剛插入的按鈕如果沒有指定巨集，怎麼點都不會有反應。老師課堂上就遇到一次，他的說法是「你沒有給他功能，他怎麼點都沒有用」。要補指定：在按鈕上按右鍵 → 指定巨集。
18:00–24:00

5. 增益集：把工具帶出這個檔案，別人也能用

前面兩章做出來的東西有一個共同限制：換一個檔案就沒了。這一章就是在拆掉那道牆。

老師用一個大家都看過的例子解釋什麼是增益集：Excel「資料」頁籤裡的「資料分析」——那個能一鍵做描述統計的功能，本來就不是 Excel 內建的，而是別人寫好、你安裝上去的增益集。「那如果我想要自己寫，比如說像這樣寫出自己的統計分析，我只要把我的檔案傳給別人，別人就可以去做使用。」

三種副檔名，決定這個工具能走多遠

副檔名是什麼能做到什麼
.xlsx一般活頁簿只有資料。存不了巨集，錄完關檔就消失
.xlsm啟用巨集的活頁簿能存巨集與 VBA，但只有這個檔自己能用。檔案一換、另開一個 Excel，功能就不在
.xlamExcel 增益集裝上去之後每個 Excel 檔都能用，也能傳給別人裝。這才是「工具」

怎麼轉成 .xlam，以及裝在哪裡

老師示範了兩條路：一條是檔案 → 另存新檔 → 檔案類型選 Excel 增益集；另一條更乾脆——既然 AI 會寫程式，那就叫它寫一段把自己另存成 .xlam 的碼，直接在 VBA 編輯器裡執行。他選了第二條，「有時候如果你找不到的話，不要灰心，從哪邊改就好了。我們既然可以讓他寫程式，我們直接用程式來改」。

  1. 存成 .xlam，並把檔案放進 Excel 的增益集固定資料夾：C:\Users\<你的帳號>\AppData\Roaming\Microsoft\AddIns。
  2. 檔案 → 選項 → 增益集 → 管理「Excel 增益集」→ 執行，在清單裡勾選你的工具（老師的是「中秋烤肉資料整理工具」）。清單裡沒有就按瀏覽手動指過去。
  3. 要讓它出現在 ribbon 上：檔案 → 選項 → 自訂功能區 → 新增索引標籤，老師建了一個叫「折扣率計算」的頁籤。
  4. 在新頁籤裡新增群組，從左側命令清單改選「巨集」，找到「統一折扣率」加進去，按確定。
⚠️
增益集檔案放對位置很重要。老師特別停下來講這件事：「如果你移動了或刪除了，他就不能動。」所以他建議複製一份到 Microsoft\AddIns 資料夾再安裝，而不是直接指向桌面或下載資料夾裡那一份——那些地方的檔案你哪天順手清掉，工具就壞了。要傳給同事時，也是請對方放到同一個位置。
「所以這個為什麼要變成增益集，是有利於後續。你可能你的檔案格式是非常非常的固定，你每個月都要做相同的事情，你每張報表都是同樣的格式，只是因為數字有差。」
［23:35］他用這句話總結整個練習一。判斷要不要做成增益集的標準不是「難不難」，是「這件事你一個月會做幾次」。
🔧
逐字稿在這一段把「增益集」聽成了「爭議集」「正義集」「登義集」，「巨集」聽成「聚集」「劇集」，「VBA」聽成「BBA」。本頁引文都已依上下文與畫面校正回正確用詞，但沒有更動老師的說法本身——例如他把 .xlam 講成「增益集的檔案格式」，本頁照樣保留。
24:00–30:40

6. 把 Power BI 交給 ChatGPT：外掛、假資料、四行提示詞

課程走到一半，老師先按下暫停：「剛剛 AI 在哪邊幫助我們，那跟今天的主題的 Power BI 有什麼關係呢？」接下來六分鐘，是這堂課的轉折點。

先裝外掛：ChatGPT 的 Power BI Desktop 外掛程式

他提到 ChatGPT 大約半年前更新了外掛程式（Apps／Connectors）機制，Power BI 是其中一個。安裝過程比想像中簡單——不用登入 Power BI 帳號、不用付費、按「立即使用」就能開始用。

  1. ChatGPT 左側選單點「外掛程式」。
  2. 搜尋 Power BI，找到 Power BI Desktop。
  3. 按安裝外掛程式，再按立即使用。
  4. 之後在對話框按 @（老師講「小老鼠」）就能叫出它。

對照簡報第 18 頁，這個外掛能做的事被整理成四類：

功能ChatGPT 可以做什麼實際例子
讀模型看 Tables、Columns、Measures、Relationships「這個模型有哪些資料表？」
寫 DAX根據自然語言產生 DAX Query「幫我算今年與去年營收成長率」
查資料真的向 Power BI 模型查詢資料「找出營收最高的前 10 個科別」
看報表查看頁面、圖表、欄位、篩選器「這份報表目前有哪些視覺化？」

上傳資料之前，先想一件事

「如果你的 Power BI 的內容，你的 data 是不能上雲端的，你的做法就是給他假資料。好，給他假資料。然後你再換成你的真資料。你只是需要他的架構而已。」

四行各有各的任務，老師在口述裡都交代了理由：

  • 講目的不講畫面　——「快速掌握食材的銷售情形」是一句業務需求。他要的是讓 AI 自己判斷該放哪些指標。
  • 點名要 DAX　——不指定的話 AI 可能只給你圖表，不會建立可重用的量值（Measure）。
  • 同時要 zip 和 HTML　——這是老師的小技巧。他的說法是「我需要先看看模式長怎麼樣，就是 HTML 檔，先看看他長怎麼樣」。HTML 可以直接用瀏覽器開，先確認方向對不對，再花時間開 Power BI Desktop。

7. Power Query：整理一次，以後只要按「重新整理」

趁 AI 在背景生成儀表板的空檔，老師回頭補上被跳過的那一段：資料是怎麼清乾淨的。

「我如果以一般來說要進入到 Power BI 之前，通常都要先把資料清乾淨。先把資料清乾淨。」
［31:19］整堂主線就是這一句，他還講了兩遍。前面的巨集與 VBA 是「用程式清」，這一章是「不寫程式也能清」。

他形容 Power Query 是「輕量版的 Power BI」：介面幾乎一樣，但它只做一件事——把資料整理成可以分析的樣子。最大的賣點是「不用寫函數，不用寫相關的內容」。

怎麼打開

  1. Excel 的「資料」頁籤 → 取得資料。
  2. 選「啟動 Power Query 編輯器」（或「從檔案」匯入外部檔案）。
  3. 匯入時勾選「選取多重項目」，可以一次挑好幾張工作表。老師先匯入 PQ練習_髒資料。
  4. 在右側查詢清單點兩下，資料就進到編輯畫面。

五個清理動作，全部靠點選

要解決的問題在哪裡點做完會發生什麼
整列空白常用 → 移除資料列 → 移除空白資料列第 16 列那種空殼直接消失
整列重複常用 → 移除資料列 → 移除重複的項目老師示範的是 9/12 桃園場那兩筆一模一樣的無糖茶
「臺灣」與「台灣」混用轉換 → 取代值整欄套用規則，不是改一個儲存格
看不見的前後空白轉換 → 格式 → 修剪「臺灣 」和「臺灣」在報表上長得一樣，實際是兩筆資料——修剪之後才會合併
單價混著「NT$」「元」「盒」新增資料行 → 自訂資料行建一個乾淨的「標準單價」新欄，再把型態改成整數
💡
老師介紹取代值時說「就跟我們平常用搜尋的時候一模一樣的概念」，但兩者其實差一個關鍵。簡報第 15 頁把這個差別寫得更準：「不是改一個儲存格，而是對整個欄位建立轉換規則。」（此句取自簡報畫面文字，不是課堂口述）Excel 的尋找取代改的是這一次的資料；Power Query 的取代值改的是規則——下次資料換了，同一條規則會自動再跑一次。

比較複雜的欄位（數量的「8盒」、折扣的「9折」、是否冷藏的 Y／是／TRUE 混用），他一樣的處理方式：新增自訂資料行，公式請 AI 寫。「這時候公式請 AI 幫你寫，把所有的單價的公式寫好，用 Power Query 的方式。」寫完貼進去按確定，整欄一次算完。

右邊那份「套用的步驟」，才是真正的成品

Power Query 的價值不在某一次清乾淨，而在它把你做過的每一步記成一份清單。下個月拿到新資料，把檔案換掉、按「全部重新整理」，這份清單會從頭再跑一次。

合併查詢：把兩張表接起來

最後一段他做了 PQ練習_髒資料 與 Dim_品項 的合併，順便把 Power BI 的核心觀念先講了。

  1. 把 Dim_品項 也匯入 Power Query。
  2. 常用 → 合併查詢。上面選主資料表、下面選要接上來的那張。
  3. 兩張表各點一次「品項編號」欄當作連接點（下面那張要按住 Ctrl 選）。
  4. 聯結種類選「左方外部（第一個資料表的所有列，第二個資料表相符的列）」。
  5. 合併後點欄位標題旁的雙箭頭，勾選要展開的欄位（老師選了單位重量_公斤、分類、標準產地、單位）。
💡
「兩張資料表要有一個連接點」——老師特別說「這個用在 Power BI 也是同樣的概念」。這就是簡報裡講的星狀模型：一張交易大表（採購資料）＋幾張小的維度表（品項、活動），靠共同欄位建一對多關聯。在 Power Query 叫合併查詢，在 Power BI 叫關聯性，是同一件事。

做完之後關閉並載入，整理好的資料就回到 Excel 工作表，可以直接交給 Power BI。老師的提醒是「你是不是很怕它東西不見？你就按儲存」——Power Query 的步驟是存在活頁簿裡的，關掉編輯器不會弄丟。

教材裡預先寫好的 DAX 公式

如果你不想等 AI 生，或想確認 AI 生出來的對不對，教學任務與DAX 這張表把八條量值的完整公式都寫好了：

總採購金額 = SUM('中秋烤肉_採購資料'[總成本_NT$]) 平均單價 = AVERAGE('中秋烤肉_採購資料'[單價_NT$]) 採購筆數 = COUNTROWS('中秋烤肉_採購資料') 品項數 = DISTINCTCOUNT('中秋烤肉_採購資料'[品項編號]) 平均每筆成本 = DIVIDE([總採購金額],[採購筆數],0) 肉類採購金額 = CALCULATE([總採購金額],'中秋烤肉_採購資料'[分類] = "肉類") 預算差異 = SUM('Dim_活動'[預算_NT$]) - [總採購金額] 預算執行率 = DIVIDE([總採購金額],SUM('Dim_活動'[預算_NT$]),0)
💡
這八條的排列是有教學順序的：SUM → AVERAGE → COUNTROWS → DISTINCTCOUNT 是基礎聚合，DIVIDE 是「避免除以 0」的安全寫法，CALCULATE 是 DAX 真正的分水嶺（加條件的聚合），最後兩條則是跨資料表計算——必須先建好 Dim_活動 的關聯才算得出來。照這個順序練，比隨機查函數有效率得多。

TAKEAWAYS

10. 這堂課真正在教的事

把 50 分鐘濃縮成四件事。這四件都不是操作步驟，是判斷。

一、決定用哪個工具，看的不是難度，是「這件事你會做幾次」

「什麼時候用巨集、什麼時候用 VBA、什麼時候用增益集」是老師開場說最多人問他的問題，而他給的答案不在功能表裡。做一次就好 → 手動；每週都要做 → 錄成巨集；要穩定重複跑 → 讓 AI 改成 VBA；每個檔案都要用、還要給同事 → 轉成 .xlam 增益集。同一件事在四個層級各有各的成本，選錯不是做不出來，是浪費。

二、AI 在這堂課只負責一件事：把你的動作翻譯成程式碼

整堂 AI 出場四次，做的都是同一件事——VBA 由它改寫、Power Query 的自訂資料行公式由它寫、DAX 量值由它建、儀表板版面由它排。它沒有替你決定「折扣率該怎麼定義」「哪些指標重要」，那些一直是你的工作。看懂這個分工，才不會誤以為把檔案丟給 AI 就會有答案。

三、資料不能上雲端，不代表不能用 AI

「給他假資料，然後你再換成你的真資料，你只是需要他的架構而已」——這句話的價值遠超過它在課堂上佔的 15 秒。AI 生成的是欄位結構、公式與版面，跟資料內容無關；準備一份欄位相同、數字亂填的樣本，拿回架構後在本機換上真資料，公司的資料一筆都沒有離開過。這是很多人以為自己「不能用 AI」時，其實可以走的路。

四、AI 給的是架構，最後一哩路還是你的

這堂課最誠實的一段在最後六分鐘：AI 生出來的 Power BI 專案打開時，跳出兩條警告，關聯要手動重新整理，老師現場等了將近兩分鐘。他沒有跳過，也沒有假裝一次成功。結論不是「AI 不好用」——四行提示詞換來一個含 11 個 DAX 指標的完整專案，這已經省掉一兩個小時；結論是要預期最後有一段收尾要自己做，並且知道那段是什麼（檔案位置別動、按重新整理、看驚嘆號在哪張表）。

［00:30］開場第一句就把重點挪走。整堂 50 分鐘，只有最後 10 分鐘真的碰 Power BI。
「再來他也可以轉成增益集，你就可以帶著走。」
［04:16］開場預告三個工具的關係時說的。「帶著走」三個字是增益集存在的全部理由。
「如果你希望別人也可以用的話，就是要轉成增益集的檔案格式。」
［04:30］巨集與 VBA 是自己用，增益集是給別人用——這是那個常見問題最短的答案。
「你一定要把你的 Excel 檔先做一個轉檔的動作，通常要 XLSM 檔它比較適合巨集的方式。」
［06:00］錄製巨集之前最容易漏掉的一步。忘了轉檔，錄再久關檔就沒了。
「你就不用浪費時間。比如說我到底要怎麼去統一我的格式。」
［09:20］全堂第一次把工作交給 AI。他要的是折扣格式的轉換公式，而不是自己翻函數說明。
「所以這個為什麼要變成增益集，是有利於後續。你可能你的檔案格式是非常非常的固定，你每個月都要做相同的事情，你每張報表都是同樣的格式，只是因為數字有差。」
［23:35］判斷要不要把工具做出來的標準：頻率，不是難度。
「如果你的 Power BI 的內容，你的 data 是不能上雲端的，你的做法就是給他假資料。好，給他假資料。然後你再換成你的真資料。你只是需要他的架構而已。」
［26:46］全堂最值得抄下來的一句。解決的是「公司資料不能外傳所以我不能用 AI」這個誤解。
「當然他也可以手把手的教你。比如說你打開 Power BI 跟他說 step by step 的教我怎麼建，他會一步一步的教你建。」
［30:00］同一個外掛的兩種用法：幫你做完，或是教你自己做。取決於你想學會什麼。
「我如果以一般來說要進入到 Power BI 之前，通常都要先把資料清乾淨。先把資料清乾淨。」
［31:19］講了兩遍。這是整堂課的主線，也是為什麼前 40 分鐘都在講 Excel。
「這邊有一個取代值。就跟我們平常用搜尋的時候，一模一樣的概念。」
［35:45］他用大家熟悉的尋找取代來破冰。差別在於：Excel 改的是這一次的資料，Power Query 改的是會一直重跑的規則。
「這時候你就可以大幅度的降低你原本在那邊拉來拉去的動作。你在前面把你的需求寫得越清楚，寫得越完整的時候，他就會越有效的去做打開的動作。」
［46:30］回答「為什麼四行提示詞就夠」。省的不是打字時間，是在 Power BI 裡試版面的那一兩個小時。
「驚嘆號代表他沒有立馬連上。你的資料可能在不同的地方。」
［47:49］現場等關聯重整時說的。他把卡住的原因當場講清楚，而不是重開一次假裝沒事。
「所以基本上以前 Power BI 要搞很久，現在他快速的可以去幫你做一些整體性的處理。」
［48:59］收尾。也是他建議的練習順序：先玩巨集與增益集，再玩 Power Query，最後才請 AI 生 Power BI。
