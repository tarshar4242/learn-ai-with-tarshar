# 交付前自檢閘門

## 這份 Skill 不新增任何規則

裡面每一條都出自既有正本，只是把散在多處的敘述句翻成可以逐條勾的執行步驟。出處欄標明來源，內容有出入時**以正本為準**，並回報 Tarshar 對齊。

正本：`AI-COLLAB.md`、`CLAUDE.md`、`README.md`、`AI資料位置共識.md`。

**為什麼要有這份**：2026-08-25 月復盤交付時貼出未 percent-encode 的 GitHub 連結，Tarshar 在手機上點到 404。規則當時就寫在 `CLAUDE.md` 裡，問題不是沒有規則，是規則寫在第 106 行、當下沒讀到那裡。這份把它變成必經步驟，讓執行不依賴記憶。

`README.md` 第 142 行原本就寫著「工作結束照 `sop/收官流程.md` 走」，但那份檔案未曾建立。本 Skill 即為該空位的實作。

## 什麼時候跑

- 即將對 Tarshar 說「做好了」「已放進圖書館」「已上線」「已完成」「交付」的任何一句話之前。
- 一個階段性任務收尾時，不等她提醒（出處：`AI-COLLAB.md`〈階段性收官與網址交付（強制）〉）。
- 她說出上方任一觸發語時。

不必跑的情況：純查詢、純討論、還在中途沒有產出檔案。

- **同一則訊息就附上可以直接點的連結**，不可以只講檔案路徑，不可以要她自己去 GitHub 或網站找。產出的檔案（影片、簡報、文件）直接傳給她。（出處：`CLAUDE.md` 規矩 4）

- **主動問她要不要現在開啟、查看或本人驗收**；若該網址還不能對外分享，同時標明可見對象與限制。（出處：`AI-COLLAB.md` 收官第 4 條）

## 兩個實作細節

### percent-encode 指令

```bash
python3 -c "import urllib.parse;print(urllib.parse.quote('300_Journal/2026-08/月復盤｜八月｜主軸.md'))"
```

把輸出接在 `https://github.com/tarshar4242/<repo>/blob/<分支>/` 後面。

### 兩種驗證方式（別用錯）

| 對象 | 怎麼驗 | 注意 |
|---|---|---|
| **公開網址**（GitHub Pages、對外網站） | 實際抓一次，確認回 200 且內容正確 | 抓不到就是真的有問題，要修 |
| **私人 repo 的檔案連結** | 用 `git ls-tree <分支> -- '<路徑>'` 確認遠端分支上真的有這個檔案 | AI 匿名抓私人 repo 一定 404，**這不算驗證失敗**，不要因此跟她說「驗證失敗」（出處：`CLAUDE.md` 規矩 4） |

### 分支這一項要特別講清楚

在雲端 session（Claude Code on the web）工作時，push 常常落在 `claude/xxx` 開發分支而不是 `main`。這時：

- 連結要用該分支的路徑，不是 `blob/main/`。
- 要主動告訴她「這在分支上，還沒進 main」，並問她要不要合併。
- 不主動開 PR，除非她說要。
