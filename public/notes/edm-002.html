電子報 002｜2026.07.31

一份簡報躺在那裡不會說話，
五分鐘後它自己會講課了 🎬

簡報變影片 語音合成 自動字幕 Claude Code

📄我手上有一份很好的簡報

十三頁，講 Power BI 怎麼做業務數據分析。內容我很滿意，圖也漂亮。但它就是一份 PDF，安安靜靜躺在那裡。

學員下載回去，看得懂嗎？看得懂一半。因為簡報上寫的是重點，重點旁邊那些「為什麼」，本來是要我站在旁邊講出來的。

可是我不可能每個人都講一次。所以我想試試看：能不能讓這份簡報自己開口。

🙋我開的條件也有點貪

我要的不是把字唸出來。我要它像有個老師在旁邊講解，講到你懂為止。

然後：要有字幕，因為很多人是在通勤、在午休、在不方便開聲音的地方看。字幕還不能亂跳，要跟聲音對得準。

最後，我不想學新軟體。我沒有時間再去搞懂一套剪輯工具的介面。

✋我只做兩個動作

第一個動作：把 PDF 丟給 Claude，說「我想把它做成影片，要配字幕跟語音」。

第二個動作：它先做了前八頁的短片給我看，我聽完說「可以，繼續」。

中間這條線是這樣跑的：

  • 👀它把每一頁「看過」，不是抓文字，是真的看圖，看懂這一頁在講什麼
  • ✍️幫每一頁寫一段口播稿，講課的口吻，不是照唸投影片
  • 🎙️合成台灣中文女聲旁白
  • 💬把旁白切成一句一句，對回聲音的時間點，做成同步字幕
  • 🎬圖、聲音、字幕組成 1080p 影片

五分二十一秒的成品。我全程沒有打開過任何一個剪輯軟體。

🗝️我在這裡藏了一個原理

這次最關鍵的一句話是：

先看一小段，再跑一整批。

一開始它就要直接做全部。我讓它停下來，先做八頁給我聽。因為如果聲音我不喜歡、語速我嫌快、字幕位置我覺得擋到圖，做完整部再來改，等於整批重做。

這不是 AI 的規矩，是我自己給自己定的規矩。任何一次大量產出之前，先要一個樣品。這一步花五分鐘，省下的是後面的整個下午。

😅途中還真的出了一件事

系統一開始告訴我們這份 PDF 有一百七十二頁。我心想，那不就要做成一小時的影片。

結果它去查了實際頁數，只有十三頁。那個一百七十二是檔案內部圖層的數量，不是頁數。

我很喜歡它處理這件事的方式：不是照著錯的數字硬做，也不是編幾頁出來湊數，而是停下來查清楚，然後告訴我「這裡跟一開始講的不一樣」。

這件事後來被寫進流程裡：動手之前，先自己確認一次數字。

📚然後我把它變成一個技能

做完影片我做了第二件事：請它把整套流程寫成一份「技能」，存進我的圖書館，推上 GitHub 主線，三方協作都看得到。

怎麼寫口播稿講課口吻、每頁幾句、數字要寫成中文讀法
先示範再全跑超過二十頁的簡報，一律先做短片給我確認
環境怎麼準備包含這次卡住的那個網路憑證問題，寫下解法
交付前怎麼驗抽畫面看字幕有沒有燒上、有沒有對到那一頁

意思是，下一次我只要說「這份做成影片」，這一整套會自己跑起來。今天踩過的坑，明天不用再踩第二次。

⚖️我做過的兩個取捨

一，先用現成的聲音，不等完美。我問過能不能用我自己的聲音。可以，但要另外申請服務、要付月費。我選擇先用現成的台灣女聲把整部做完，先有一個能交的成品。想換聲音的時候再換，稿子和流程都還在，前面的工不會白費。

二，接受它現在還不夠有我的味道。旁白現在講得很清楚，但還是有點像一個很專業的陌生人。我知道差在哪：少了我平常上課會冒出來的那些話。這是下一版要補的，但不是現在不交件的理由。

🚀下一步

兩件事。第一，讓口播稿更像我在講，把我上課常用的比喻、常說的口頭禪放進去，讓它有我的顏色，而不是一份標準的旁白。

第二，如果第一步做到了，再來考慮換成我自己的聲音。順序不能反過來，因為就算聲音像我，講出來的話不像我，一樣還是別人。

💬想跟你說的一句話

我們常常在等一個完美的版本才敢交出去。但這次我學到的是，先有一個「已經能用」的東西，比一個還在腦袋裡的完美計畫值錢太多了。

影片現在不夠有我的味道，我知道。可是它已經能讓看不懂那份簡報的人看懂了。那它就已經在做事了，而我可以邊用邊改。

還有，我一樣不會寫程式。我做的還是同一件事：把我要什麼講清楚，然後在該喊停的地方喊停。
