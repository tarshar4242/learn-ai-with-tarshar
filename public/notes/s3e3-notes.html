聲音復刻 × 貼課通：把單檔 AI 工具送上雲端

這一堂益師傅一次示範兩套自己用 AI 打造的工具：一是「聲刻 Voice Foundry」——放一段 10～30 秒的乾淨人聲，就能在自己電腦上用相同音色把任何文字唸出來，還能拆成多角色 Podcast（含台語）；二是「貼課通」課堂即時牆——開一間房，全班連進來貼文字／圖片／影音，配上舉手、匿名提問、理解度紅綠燈、搶答、評分、協作白板等一整排互動功能。
但真正的重點是最後那一課：這些都是「純前端單檔 HTML」，可以用 CAST-STUDIO.exe 本機小伺服器雙擊即用，也能嵌進 Google Sites 一鍵發布成公開網址，任何人打開就能用。本頁依兩段錄影逐幀（每 15 秒一格、共 585 格）＋全程逐字稿整理，重點段落附影片時間戳。

3. 主角一：聲刻 Voice Foundry（本機聲音克隆） [17:45 起]

雙擊 聲刻.exe，瀏覽器打開 127.0.0.1:7860，就是「聲刻 VOICE FOUNDRY」——標語「留住聲線，重新說話」（OPEN-SOURCE VOICE CLONING · LOCAL FIRST）。

聲刻是什麼、為什麼要「可攜版」

  • 本質：一個跑在你電腦上的本機 web app（Python 服務 + 瀏覽器介面，port 7860）。放一段乾淨人聲＋輸入新文字，它就用相同音色產生全新 MP3。
  • 可攜版打包：老師把它打包成「聲刻-可攜版」——內含免安裝的內嵌 Python（python-3.12.10-embed）＋模型快取＋聲刻.exe 啟動器，整包約 7 GB，換電腦解壓即用。
  • 啟動提醒：看到「模型已就緒」再按生成；啟動後超過 3 分鐘仍無畫面＝啟動失敗。

算力：GPU 快、CPU 慢（但都能跑）

情境速度
啟動與模型載入約 5～30 秒
150 字（一般段落）約 2～4 分鐘（CPU 模式）
500 字約 6～8 分鐘
Podcast 多段內容可能 10～30 分鐘以上
⚠️
RTX 50 系列（5060／5090…）常見 CUDA 錯誤：「CUDA error: no kernel image is available for execution on the device」。原因是內建的 PyTorch/CUDA 版本不支援這張新顯卡的架構，不是聲音檔壞掉。聲刻會自動退回 CPU fallback（能跑，只是慢）。修法見第 11 節。

4. 對照組：ElevenLabs 雲端 TTS [06:45–17:00]

在示範本機聲刻之前，老師先帶大家看雲端的對照組 ElevenLabs（elevenlabs.io），讓大家理解「雲端 TTS」與「本機克隆」的差別。

三個模型、怎麼選

模型特色
Eleven v3最具表現力，支援 70+ 語言，可用 [laughing]／[whispers] 等 audio 標籤控制語氣，也能生成多講者對話
Eleven Multilingual v2Studio 級品質、最自然、情感最豐富，支援 29 語言，適合旁白／有聲書
Eleven Flash v2.5便宜 50%、延遲最低，支援 32 語言，適合對話式即時應用

音色庫、我的音色、音色設計

✅
老師的小技巧：要寫音色描述時，先請 AI 幫你寫一段形容詞（例：「請給我一段描述台灣中年男子、嘮叨但精神奕奕的聲音形容詞，用 50 個字」），再把那段話貼進 ElevenLabs 的音色設計，音色就更到位。

API Key：一個工具開一把「受限金鑰」

如果你要在別的工具（例如聲刻的 CAST、或自己的程式）串接 ElevenLabs，就要到「開發者 → API 密鑰」建立一把 key。老師示範建立時的重點：

  • 開啟「限制密鑰」，把用不到的權限關掉（Endpoints 逐項可設「無存取權限／存取」）。
  • 可設到期時間、用量限制（點數）。
  • ElevenLabs 有「若外洩則自動停用」：偵測到金鑰被公開（例如上傳到 GitHub）會自動停用，是很貼心的防呆。
  • 金鑰產生後只顯示一次，關掉對話框前務必複製。
🔑
金鑰＝帳號密碼，不可分享。一個工具開一把受限金鑰，出事只影響那一把。ElevenLabs 音色化（克隆）與音色設計會消耗點數（花錢）；聲刻則是本機跑、不花這筆錢。

CAST

6. CAST：Podcast 多角色工作室 [19:00 起 · 44:00 生成]

聲刻的第二個分頁是 CAST（AI PODCAST 語音生成工作室）：貼上一份素材，AI 直接寫出完整訪談文案，再在本頁合成語音，輸出 MP3 與字幕 MP4。

8 步驟精靈

  1. 貼上文章自動填表：上傳 txt／md／pdf／html，AI 解析後自動填好下面各欄（需 Groq API Key）。
  2. 分析主題：例「親子餐廳企劃分析」（快速標籤：AI 趨勢／創業／股市解盤／STEAM 教育…）。
  3. 目標聽眾：初學者／一般大眾／專業人士／主管／投資人——影響術語密度與解釋深度。
  4. 情緒節奏曲線：W 型起伏（最受歡迎）／漸強式／先高後穩／雲霄飛車（辯論激烈型）。
  5. 主持人設定：1 人獨白／2 人對談／3 人圓桌；每位主持人可設姓名、語言、性別、語氣風格、人設專長。
  6. 焦點關鍵字：節目中必須提及的詞彙或數據。
  7. 禁止提及：不得出現的主題或詞彙。
  8. 節目設定：自我介紹、節目長度（短／中 8–12 分／長）、互動風格。

兩個亮點：台語主持人＋聲音混搭

  • 台語（意傳）：主持人語言可選「台語（意傳）」，由意傳科技「嘀聲」合成（免 Key、免費展示限流 3 句/分鐘）；可選台語聲線 1／2／3 以變調區分講者。教材使用要標示「語音來源 意傳科技」。
  • 聲音可混搭：主持人 A 可用聲刻本機 Clone Voice（你自己的聲音）、主持人 B 用 ElevenLabs（George、Sarah…）或台語——本機與雲端聲音同表選用。
  • 試聽引擎：可切「ElevenLabs V3（高品質，需 API Key）」或「聲刻本機 Clone Voice（免 ElevenLabs Key）」。
💡
快速模板很豐富：產業分析、職涯諮詢、技術解讀、正反辯論、新聞快報、教學課程、人物訪談、故事說書，加上特殊領域（八字命理、姓名學、股市解盤）。選一個就自動帶入主持人設定與節奏。

7. 主角二：CAST STUDIO 獨立版 [第二段 02:00 起]

下半場老師先秀 CAST-STUDIO-win.exe——就是把上面 CAST Podcast 工作室單獨打包成一個 Windows 執行檔（約 15 MB），雙擊後自己開瀏覽器，跑在 127.0.0.1:59767。

技術揭密：為什麼要「本機小伺服器」

老師打開 Claude 對話（帳號「益師傅・Max」）秀出這個工具的設計原理，這段很值得懂：

運作方式（Codex/Claude 幫忙設計）： ① 雙擊 CAST-STUDIO-win.exe → 啟動本機小伺服器（僅監聽 127.0.0.1）→ 自動開瀏覽器載入介面 ② 內嵌 /p 免 CORS 代理：台語標音/合成、TWSE、TPEx 都由 exe 伺服器端抓 → 不再需要 Cloudflare Worker（伺服器端發請求，所以「天然無 CORS」） ③ 自動偵測執行環境：localhost 走本機代理；開網頁版 HTML 則退回 Worker（同一份介面兩用） ④ ElevenLabs / Groq / Pollinations / ffmpeg 等原本就開 CORS 的服務照舊直連
🧩
白話：瀏覽器有個安全限制叫 CORS（跨來源請求會被擋）。把工具包成一個「本機小伺服器」，請求改由伺服器端發，就繞過了這個限制——這就是為什麼要做成 .exe 而不是純網頁。老師還提到已在沙盒實測：HTML 內嵌成功、白名單外網域正確回 403、代理轉發鏈路正常。

8. 主角三：貼課通課堂即時牆 [第二段 07:30 起]

第三個工具是 貼課通（課堂即時牆・專業版）：老師用 Edge 打開本機的 貼課通-教師專業版.html，開一間房，全班連進來一起貼。

KEY LESSON

10. 關鍵一課：把單檔工具送上雲端 [第二段 17:00 · 33:00–39:00]

這是本堂最重要的觀念。學員耀州先主動用 AI 拆解貼課通的原理，問 Codex「這個程式可改成 GAS 嗎？變成雲端服務」，得到關鍵答案：

老師走通的路：嵌進 Google Sites → 一鍵發布

  1. 開 Google Sites 新網站，新增一頁。
  2. 用「內嵌 ＜＞」→ 自訂內嵌（貼程式碼），把貼課通學生版整頁嵌進去。
  3. 右上「發布」，網址填 ecf-class → 得到公開網址 sites.google.com/view/ecf-class。
  4. 誰可以查看：所有人 → 發布 → 「您的協作平台已成功發布」。
  5. 用無痕視窗開這個公開網址，貼課通學生版正常載入、能加入房間、能貼文——完全走通。
✅
當堂最有感的一幕：發布後，全班學員紛紛複製老師做法，把貼課通嵌進自己的 Google Sites、發布成自己的網址，再把成果截圖貼回牆上互相展示。一堂課下來，全班都學會「把單檔工具掛上雲」。
⚠️
資料保存提醒：有學員問「離開頁面資料就不在，我可以安裝在自己的雲端伺服器嗎？」——可以。純前端工具的資料存在瀏覽器（IndexedDB／LocalStorage），關掉就清掉；要長期保存就自己部署（GAS／Google Sites／自架伺服器），並善用貼課通的「匯出／專案庫」把牆面存下來。
