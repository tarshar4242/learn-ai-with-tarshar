研究問題與比較條件

RQ1 保留為設計問題：能否建立可操作、可重複的外化導向流程？證據為設計映射、原型及驗收，不強套顯著性檢定。RQ2 建議聚焦：AI 引導整套工具相較人工整理，最終經驗表達品質有何差異？RQ3 用完成率、耗時、負擔、滿意度與隱私顧慮作次要量化評估。

本輪新提案 C：同一八欄位由本人自行整理、不使用 AI、不追問；T：同樣八欄位，使用 AI 五問與有限追問後核對。這已不同於完全無欄位的自由敘述，必須由 TAR／教授確認。即使格式相同，T 仍同時含追問與自動整理，只能估整套工具的差異，不能單獨歸因 SECI 或 AI。若改成同模型一般聊天對照，應同步改研究問題，不能在工程階段偷偷替換。

獨立變項是整理方式 C／T；主要依變項為最終品質總分。控制任務目的、說明、裝置規則、時限、欄位與研究者協助方式。只記必要的經驗熟悉度、AI 熟悉度與裝置，不為湊模型蒐集過量背景資料。

每人兩事件的流程草案

參與前確認兩件事件 E1／E2 的簡短標籤與熟悉度，不先完整訪談。四序分派為 T(E1)→C(E2)、C(E1)→T(E2)、T(E2)→C(E1)、C(E2)→T(E1)，每四人一區塊隨機分派並保存亂數種子。個人事件標籤僅留前端，研究庫存 E1／E2；難度相近是待試測假設，不宣稱已等價。

預估流程 40 分鐘：告知及操作說明 5 分鐘、確認事件 3 分鐘、第一條件 14 分鐘、休息 2 分鐘、第二條件 14 分鐘、回饋 2 分鐘；同意閱讀可延長。每條件暫分整理 10 分鐘與核對 4 分鐘，含 API 等待；超時未完成另記，不強迫捏造內容趕交。這是預試待校準的程序，並非時間績效承諾。

風險：平衡順序不能消除學習移轉。 先看過 AI 追問可能學會人工整理。換事件或休息也不保證消除；預試若顯示嚴重移轉，正式研究前改評受測者間設計並重算人數。不能事後只取第一輪或以順序不顯著宣稱無移轉。交叉設計參考。

04評分規準與分析計畫

主要品質分數

候選主要分數為六面向各 0–3 分、合計 0–18，再取兩名真人評分者平均；這是研究者自編規準，不是已驗證 SECI 量表。共用錨點為 0 無證據、1 泛稱或核心含糊、2 具體且主要關係清楚但仍缺重要細節、3 具體且關係完整。

面向低分與高分的判斷例
情境與目標1「那天很忙」；3 說清問題、限制及要達成的目標
判斷線索1「憑經驗」；3 說清看到什麼、如何辨認異常
選擇理由1「比較好」；3 將線索連到選擇並解釋取捨
行動與條件1「處理一下」；3 步驟可操作且含何時調整
例外與界線1「視情況」；3 交代哪些條件不適用或需改法
傳達清晰度1 關鍵代詞或關係含糊；3 新手可理解前述關係

例子僅說明錨點，正式前須補每面向四級範例，請真人審查內容適切性，再以 4–6 件非正式產出訓練兩位評分者。不能以欄位填滿、字數多或排版漂亮代替實質品質；「不適用」的計分規則須事前固定。

去除方法、時間與個人識別標籤、統一呈現格式並打散所有卡片，再獨立評分。保留原始分數，先計算一致性再依預定規則處理差異。AI 文風仍可能暴露組別；應記錄此限制，不能保證完全盲評。

總分可用兩因子混合、絕對一致、兩評分者平均分的 ICC 與 95% 信賴區間；若欲推論其他評分者，須另選隨機模型。每人兩件產出有群聚，區間估計應保留受測者層級。高一致不等於效度好，小樣本 ICC 區間可能很寬。ICC 方法指引。

分析與資料規則

正式開始前鎖定主要結果、分派、樣本停止、排除及缺漏處理。以人為獨立單位，每人一組 T−C 差值；多張卡或兩位評分者不灌成更多樣本。報所有開始、完成、退出及無評分同意的人數，不只留下成功作品。

主要報平均差、95% 信賴區間、d_z 與個人差值分布。配對 t 須檢視差值及離群影響，預先指定保留分派結構的隨機化敏感度分析；不以常態檢定結果臨時挑方法。若正式採時期／方法／案例模型，須重做模型與樣本評估；真實個人事件不共用同一客觀案例效果，不能將 E1／E2 當成所有人的同一案例。

只有一條件可評分者不能憑空補另一分數；另列完成與缺漏，說明配對分析對象及選擇偏誤。不同意內容評分可體驗，但不納入主要品質比較；不得當零分，也不得偷偷以滿意度補品質。缺漏比例上升時先檢討設計，不為顯著結果追加樣本。研究驗收不是 AI 勝出或 p＜.05。

每主問最多一次追問，全流程最多兩次，由後端控制。只在判斷線索、選擇理由或例外不明時觸發，例如：「你說『看情況調整』，當時看到哪個線索才調整？」不知道或跳過就繼續；矛盾只請澄清，不替使用者選答案。額度不足改列待確認。

輸出固定八欄：情境、問題、判斷線索、處理步驟、選擇原因、注意事項、適用限制、尚待確認事項。內部保留當次答案編號回指供本人核對，僅在頁面記憶體使用；正式研究提交可只保留確認後卡片。禁止將 AI 提議改寫成使用者曾做過的事。

06技術架構與資料保護

最小架構與資料流

候選架構是單一全端網站、後端 API 代理與支援交易的 PostgreSQL；不需要向量資料庫。文字暫存在手機頁面記憶體，經 HTTPS 到研究後端驗碼與預扣配額，再以 TLS 轉到核定供應商；結果返回手機編修及下載。後端短暫接觸內容，所以不能寫「研究者完全收不到原文」。

一般資料庫只保存去識別操作與配額資料；受測者另行同意、預覽刪改後的卡片，才進獨立受限評分庫。評分輸出移除方法標籤與識別欄位。原始經驗、完整對話與研究卡片不推 GitHub、不放公開網站；本次可公開的規劃文件與未來受測資料權限分開。

最小資料字典：研究代碼、條件 C／T、事件序號、分派序列、同意版本、開始／完成／超時、耗時秒數、跳過／修正／錯誤計數、模型與腳本版本、輸入／輸出 token、預扣／結算狀態、六項評分及評分者代碼。代碼不是姓名但仍可能連回個人，稱去識別而非保證匿名。

同意與留存

A 同意涵蓋指定供應商的雲端處理與必要操作資料；不同意就不開始 API 流程。B 同意涵蓋去識別最終卡片、真人評分與指定期限的留存；拒絕仍可體驗及下載，但品質分析不納入。聯絡資料若招募必要，由研究者另存，不進平台。

原文不寫入應用、主機、反向代理、錯誤追蹤、快取或工作階段錄影。關閉頁面後不提供原文復原；下載檔由本人管理。撤回以獨立隨機撤回碼核對，分析凍結前可刪可定位資料；完全解除連結之後不能承諾追溯刪除。保存期限與備份刪除須依校方確認方案，本稿不將任何三年／五年當既定規定。

試測與正式研究均先向教授及校方窗口確認程序，不以人少、朋友、問卷自行判定免審。淡江公開資訊可確認研究倫理與教育入口，尚未查得足以核定本案送審路徑及期限的個案規定。倫理課程證明不等於計畫核准。淡江研發處、人體研究法。

07配額成本與開發拆解

配額與失敗處理

全部參數為待確認提案：128-bit 隨機碼、每碼最多兩場、7 日到期；基本五輪處理與一次產卡為六次呼叫，最多兩次追問，共八次；含重試最多十次 API 嘗試。每次輸入上限 8,000、輸出 2,000 token；每場累計上限 80,000／20,000。每碼同時只准一請求、每分鐘六次，全域並發三次。字數不能代替 token 計數，超限需明示，不可默默截去前文。

候選金額硬上限每場 0.10 美元、每碼 0.20、每日 3、全研究 10 美元；尚未批准或儲值。後端交易同時核對已支出及已預扣，足夠才發呼叫；前端計數與供應商預算警示不能代替硬閘門。每次重試也預扣並受總次數限制。

唯一請求編號防重送；成功以 usage 結算。逾時、不明是否計費及當機後保留未結預扣，核帳後才釋放，不能直接退款再呼叫。為不持久保存內容，重送回復狀態而非永久快取原文；頁面仍可編修／下載。全域停用後不再發出新 API 請求；已送出的請求可能仍計費，原先預扣涵蓋此風險。

可重算成本

成本＝累計輸入 token × 輸入單價／百萬＋累計輸出 token × 輸出單價／百萬。每輪重送的腳本與對話都算輸入，這裡不是只算使用者一次文字。輸出額度與費用包含所有計費輸出，包括模型啟用時的思考 token。

交回 TAR 的三個核心選擇

1. 要優先保留真實經驗外化，還是採標準案例、把主張縮為資訊整理？整合建議先保留前者討論。

2. 依可邀人力與教授門檻，選 10–15 人探索性量化，或以 36 人完成作正式量化規劃？兩者都不是純滿意度問卷。
