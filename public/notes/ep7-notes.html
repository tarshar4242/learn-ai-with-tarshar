CHAPTER 01

1. AI Agent 概念：自主決策與行動的人工智慧

AI 革命普遍視作「第四次工業革命」；貫穿前三次人類工業革命的關鍵詞是「自動化」。

AI Agent（人工智慧代理／智能體）指一種能夠自主完成決策與行動的人工智慧系統，無需人類直接介入。它透過感知環境資訊，結合指令自行規劃任務並分解成多個步驟執行，並能根據回饋持續學習優化。核心融合大型語言模型（LLM），展現規劃、記憶與工具調用能力：透過「思維鏈」與「思維樹」將複雜任務分解為子目標，再用反思框架（ReAct、Reflexion）評估行動、改善表現。

OpenAI 的 AI 五級發展

  1. 聊天機器人（Chatbots）：具有對話功能的 AI。
  2. 推理者（Reasoners）：能像人類一樣解決問題。
  3. 代理（Agents）：可以正確地採取行動（重點在使用工具）。
  4. 創新者（Innovators）：可以幫助發明的 AI。
  5. 組織（Organizations）：AI 可以執行人類組織的工作。

AI Agent vs RPA（自動化流程機器人）

比較項目AI AgentRPA
解決問題擅長非結構化問題，如不確定性場景處理結構化問題，依賴固定規則
運作模式結合推理與生成式 AI 動態生成解決方案遵循預設流程，適應性低
學習優化具反思與學習能力不具學習能力，需人工更新
應用場景客服問題解決、資料搜集與報告撰寫資料錄入、自動生成報表

AI Agents vs Chatbots

項目AI AgentsChatbots
核心能力執行任務、決策與工具操作提供文字或語音回覆
智能程度可處理複雜多步驟任務多依賴預設對話模型
舉例自動駕駛車、智能家居管理系統ChatGPT、Siri、Google Assistant
CHAPTER 02

2. Claude 桌面版與快捷鍵

Anthropic 推出的 Claude AI 桌面版本支援 Windows 與 Mac。安裝步驟簡單：從官網下載相應版本（如 Apple Silicon），解壓縮後即可啟用，建議使用 Email 進行認證登入。桌面版介面與 Web 版相似，但無需透過瀏覽器操作，並提供快捷鍵能在處理其他工作時快速呼叫 Claude AI。

  • Mac 快捷鍵：Command + E
  • Windows 快捷鍵：Control + Alt + Space
CHAPTER 03

3. Analysis tool：視覺化圖表

Claude AI 的視覺化圖表功能（特別是 Claude 3.5）顯著增強了圖像分析與解讀能力，能準確識別圖表中的文字和數據並提供詳細解釋。開啟方式：點選帳號 → Feature Preview → Analysis tool → Turn on。

  1. 匯入資料進行分析：使用 CSV 檔（免費版有容量限制）。
  2. 搜尋即時資料分析：例如分析 12 強世界棒球賽中華隊數據，形成合適統計圖表。
  3. 圖形轉換：圖形產生後可轉換為 SVG 檔，下載到 PowerPoint 調整排版。
💡 SVG（Scalable Vector Graphics）是基於 XML 的矢量圖形格式，支持縮放不失真，廣泛用於網頁和圖形設計——課堂示範用它畫出「台灣國防預算趨勢圖」。
CHAPTER 04

4. Writing Style（寫作風格）＋ Customized（客製化功能）

Writing Style 三種＋個人風格

  • Formal：用於「清晰而精緻」的內容。
  • Concise：專注簡短直接的回應。
  • Explanatory：針對需要詳細解釋的場景。
  • 個人風格：可自訂屬於自己的寫作語氣。

Customized 個人化功能

設定偏好設定可讓 Claude 在回應中考慮用戶的個人化偏好，這些設定為帳戶範圍內選項。

  1. 點擊左下角的個人圖示（姓名首字母）。
  2. 選擇「設定」。
  3. 在「Claude 應考慮哪些偏好設定？」欄位描述你的偏好：處理方法、常用術語、常見情境、溝通習慣。
CHAPTER 05

5. Artifacts：即時呈現作品

開啟方式：點選帳號 → Setting → Profile → 往下拉 → Enable artifacts。Claude Artifacts 能根據對話內容動態生成多種形式的成果，包括程式碼片段、文件、圖表，甚至互動式 React 組件，且能在後續對話中持續更新與引用。使用者不僅能在獨立窗口中運行生成的代碼，還能預覽並通過連結分享。

應用範圍範例
交互式簡報資料生成 Markdown 文件、純文本文檔或結構化報告。
資料與流程視覺化使用 Plotly.js 生成交互式圖表，如數據分析儀表板。
SVG 圖形設計徽標，並可在 Artifact 窗口中修改樣式。
網站建置創建單頁或多頁 HTML 網站。
序列圖與流程圖支援流程圖、序列圖、甘特圖和 ERD。
複雜代碼結構建立管理系統的 Python 類別。
交互式網頁組件使用 React 創建動態搜索欄。
共享與協作通過連結分享 Artifacts，允許他人混搭重新編輯。
CHAPTER 06

6. Project：專案協作

Claude Projects 支援每個專案最高 200K 的脈絡長度，允許使用者添加多樣化的文件、程式碼和見解以強化 Claude 的效率。透過結合組織內部知識（風格指南、程式碼庫、採訪紀錄或先前成果），Claude 能針對不同任務提供專家級建議——例如撰寫符合企業行銷風格的電子郵件，或像資料分析師一樣撰寫精確的 SQL 查詢。使用者還能設定專案，客製化 Claude 的回應風格（正式語氣或特定角色）。

CHAPTER 07

7. Computer use：解放雙手

透過 open-interpreter，讓 Claude 直接操作你的電腦完成任務。

  1. 打開電腦命令提示字元（Windows 搜尋 CMD／Mac 是終端機）。
  2. 打上 pip install open-interpreter，按下 Enter。
  3. 跑完打上 interpreter --os，按下 Enter。
  4. 到 console.anthropic.com 網站，點「Get API Keys」。
  5. 依照畫面創建 Key，複製 Key。
  6. 到命令提示字元貼上 Key，按下 Enter。
  7. 輸入你想要 Claude 幫你完成的事情。
⚠️ 需先安裝 Python（python.org/downloads），並到 console.anthropic.com 取得 API Key 才能使用。API Key 屬敏感資訊，切勿公開分享。
