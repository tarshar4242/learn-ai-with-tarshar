## 研究問題

六個功能因素如何透過滿意度，影響人工智慧公共服務的持續使用？

## 主要發現

有用性、可靠性、安全性顯著；滿意度中介五個因素，易用性不顯著。

## 怎麼用進本研究

借滿意度三題（五點量表）與服務品質題項，改寫成查找方式版本。（研讀建議，待老師判斷）
