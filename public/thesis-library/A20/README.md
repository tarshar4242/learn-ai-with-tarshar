## 一句話判讀

可用於規劃使用者評估，不能直接證明AI回答正確。

## 研究問題

使用者評估方法哪些能用於兩種查找的比較？

## 主要發現

輪替只分散順序影響；滿意度宜多題；人機互動研究顯示主客觀僅微弱相關。

## 怎麼用進本研究

檢查任務、順序平衡、記錄、問卷與成果評分的搭配。（研讀建議，待老師判斷）

## 限制

以實驗室量化評估為主；2009年綜述有統計疑點，未測生成式回答。
