# AI 陪跑工作坊｜小組成員證網站

參考 [台北大洋流](https://current.puma.taipei) 的「領船員證、解鎖互動」機制，改成工作坊用的「選主題小組、領小組成員證、打開講義與實作存檔」。純靜態，不需要後端。

## 網址

放在 `public/ai-crew/`，隨主站部署後網址是 `https://tarshar4242.github.io/learn-ai-with-tarshar/ai-crew/`。

## 三個頁面

| 檔案 | 做什麼 |
| :-- | :-- |
| `index.html` | 首頁。沒領證：大按鈕「加入小組」，四格上鎖。已領證：秀出橫式成員證＋四格小組空間＋下一堂課倒數 |
| `id.html` | 領證。選主題小組 → 名字、照片 → 產證（直式 1080×1920）→ 分享／下載／換照片／重新領取 |
| `group.html` | 小組空間。四個分頁：課程講義、實作存檔、小組成員、課程進度。沒證會被導回領證頁 |

## 老師只需要改一個檔：`data/config.json`

- `workshop`：班名、季別、標語、簽名。
- `joinOpen`：`false` 就關閉報名，首頁按鈕變「即將開放」。
- `groups[]`：每一組的 `id`（一個英文字母，序號會用到）、`name`、`tagline`、`color`、講義清單 `handouts[]`、作品清單 `works[]`、上課時間 `schedule[]`。
  `handoutsOpen`／`worksOpen` 設 `false` 就顯示「準備中」。講義網址放雲端硬碟或站內都可以。
- `roster[]`：名冊。名字＋組別＋序號。學員打的名字對得上名冊，就拿名冊上的固定序號（例如 `2026-A-001`）；對不上就拿一組由名字算出的暫時序號，證上會提示他跟老師確認。

## 學員的照片與資料在哪

- 照片只在學員自己的瀏覽器裡裁切、貼上證，存在手機的 localStorage，不會上傳到任何地方。
- 換手機或清除瀏覽資料就要重新領證，同名同組會拿到同一組序號。
- 「小組成員」分頁只顯示名冊上的名字，不顯示照片。
