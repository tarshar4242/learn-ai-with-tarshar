# lesson-pack：教案一源多用

一份素材進來，先萃取成一份「教案核心」，再從同一個核心分頭渲染成五種產出。

## 為什麼要先萃取核心

如果每種格式各自去讀原始素材，四五份成品會各講各的——簡報講 A 重點、講義講 B 重點、教師手冊的時間又對不上。
先把「這堂課到底要教什麼」萃取成一份中間檔，所有格式都從它長出來，內容自然一致；日後要改，改核心一次，五份一起重生。

這也是為什麼核心一定要先寫進磁碟再往下做：Tarshar 的 session 隨時可能中斷，落檔的才算數。中斷後可以直接從核心續做，不用重讀素材。

## 誰會用、講給誰聽

Tarshar 是 AI 講師，主要學員是**完全沒有技術背景的新手小白**（常見場景：公部門行政人員、想入門 AI 的上班族、社群學員）。
所有產出都要能讓一個沒碰過 AI 的人看懂：白話、生活化比喻優先於術語，出現術語就當場用一句話解釋。台灣繁體中文、全形標點。

## 流程

### 步驟 0：確認素材與課程條件

先看素材是什麼、有多大：

- 純文字、Markdown、5 頁以內的 PDF → 直接讀。
- **超過 5 頁的 PDF、任何 pptx／docx 全文、zip** → 派 subagent 讀，主對話只收「重點摘要 + 檔案路徑」，不要把全文拉進主對話。這是 Tarshar 環境的硬規則，違反會讓 session 燒光 context 斷在半路。
- **影片、錄音（mp4／mov／m4a／wav）→ 一定要讀，不要跳過。** 做法見下方。

#### 影音素材怎麼讀（不要假設讀不了）

影音常常是整批素材裡資訊密度最高的一份——一支三分鐘的影片可能包含完整時間軸、關鍵人物的原話、以及最好的金句。
**先讀完再判斷它有沒有用、能不能對外使用，不要用「風險推測」代替查證。**
（這條是踩過坑寫的：曾經因為推測「影片裡可能有肖像權問題」而建議跳過，實際拆開來看是 AI 生成插畫、全片無真人，差點丟掉最有價值的素材。）

本機已備妥工具，**不需要安裝任何東西**：

```bash
# 1. 取得檔案（Drive 上「知道連結者可讀」的檔案可直接下載）
curl -sL -o video.mp4 "https://drive.google.com/uc?export=download&id=<fileId>"

# 2. 抽音軌 → 轉逐字稿（whisper-large-v3-turbo 已快取，兩分鐘影片約 20 秒跑完）
ffmpeg -y -v error -i video.mp4 -vn -ar 16000 -ac 1 -c:a pcm_s16le audio.wav
python3 -c "
import mlx_whisper, json
r = mlx_whisper.transcribe('audio.wav',
    path_or_hf_repo='mlx-community/whisper-large-v3-turbo', language='zh')
open('transcript.txt','w').write('\n'.join(
    f\"[{int(s['start'])//60:02d}:{int(s['start'])%60:02d}] {s['text'].strip()}\"
    for s in r['segments']))
"

# 3. 抽畫面 → 用 Read 工具逐張看（字卡、浮水印、有無真人臉孔都靠這步）
ffmpeg -y -v error -i video.mp4 -vf "fps=1/3,scale=640:-1" -q:v 4 frames/f_%03d.jpg
```

**不要用 Drive 的 `download_file_content` 抓影音**——它會回傳 base64 文字，一個 17MB 的影片會變成 24MB 塞進對話，直接撐爆。檔案永遠留在磁碟，對話裡只帶路徑。

畫面不用每張都看，挑開頭、中段、結尾與轉折處各一張通常就夠。要特別確認兩件事：**有沒有可識別的人臉或組織資訊**（決定能不能對外用），以及**有沒有浮水印**（例如 NotebookLM 浮水印，代表這是學員自己用 AI 做的，本身就是成效證據）。

接著確認三件無法從素材推斷、但會決定整份教案長相的事。**如果 Tarshar 已經在對話裡講過就不要重問**，只補沒講到的：

1. **課程長度與形式**（例：兩小時體驗工作坊／90 分鐘講座／半天實作課）
2. **學員是誰**（例：監理所行政同仁／完全沒用過 AI 的社群學員／已經會用 ChatGPT 想進階的人）
3. **上完課學員要帶走什麼**（一個做好的成品？一套可複製的提示語？一個觀念轉變？）

問法用選項或一句話問完，不要一題一題拷問。第 3 點若她答不出來，就用素材推一個版本給她確認——這題答案決定整堂課的骨架，不能含糊帶過。

### 步驟 1：萃取教案核心（先落檔）

寫到 `100_Todo/projects/教案_<主題>_<YYYYMMDD>/00_教案核心.md`，結構如下：

```markdown
# <主題> 教案核心

## 課程條件
- 對象：
- 時長：
- 學員帶走的東西：

## 學員現在卡在哪（痛點）
（2-4 條，要具體到能讓學員點頭說「對，就是這樣」。
 寫「不會用 AI」是無效痛點；寫「每次寫公文都要重打一次，改三輪還是被退」才是。）

## 學習目標
（3 條以內，動詞開頭、可驗收。例：「能用一句話讓 AI 產出符合機關格式的公文初稿」）

## 生活化比喻
（把這堂課最抽象的那個概念，接到學員已經懂的東西上。
 這是整堂課最值錢的部分，值得多想幾個再挑。比喻要能延伸——講完主概念後還能用同一個比喻解釋下一層。）

## 教學流程
| 段落 | 分鐘 | 在做什麼 | 學員在做什麼 |

## 操作示範
（每個示範寫成 Before / After 對照：
 Before = 學員原本會怎麼做（或給 AI 什麼爛提示），After = 換個做法的結果。
 對照比說明有效，因為學員看得到差距。）

## 常見卡點與救援
（現場一定會發生的三種卡住，各附一句救援話術）

## 練習與產出物
（學員當場要做出來的東西。沒有產出物的課，學員回家就忘了。）

## 金句 Golden Line
（1-2 句學員會抄進筆記、會轉發的話）
```

核心寫完，先讓 Tarshar 看一眼再往下渲染。核心錯了，五份一起錯。

### 步驟 2：分頭渲染

每完成一份就寫進磁碟，再做下一份。完整版型看 `references/templates.md`。

| # | 產出 | 檔名 | 讀者 |
|---|---|---|---|
| ① | 簡報大綱 | `01_簡報大綱.md` | 投影片，一頁一頁 |
| ② | 學員講義 | `02_學員講義.md` | 學員帶回家 |
| ③ | 教師手冊 | `03_教師手冊.md` | 只有 Tarshar 看 |
| ④ | AI 協作手冊 | `04_AI協作手冊.md` | 下一次的她 + 下一次的 AI |
| ⑤ | 學習日誌素材 | `05_學習日誌素材.md` | 交棒給 `journal` skill |

預設五份全出。她若說「只要講義」「這次不用教師手冊」，就只渲染指定的那幾份——但 ①②③ 建議成套，因為三者的時間與段落必須對得起來。

### 步驟 3：交付與交棒

交付時給她：資料夾路徑、五份檔名、一句「你現在可以怎麼用」。
最後提醒一句：⑤ 已經備好，她想寫今天的日記時可以直接說「寫日記」，`journal` skill 會接手。

## ④ AI 協作手冊 和 ⑤ 學習日誌素材 的界線

這兩份最容易寫成同一份，寫混了兩份都會沒用。判準是**主角是誰**：

|  | ④ AI 協作手冊 | ⑤ 學習日誌素材 |
|---|---|---|
| 主角 | 這段合作關係 | Tarshar 這個人 |
| 在記什麼 | 誰做什麼、哪裡卡住、下次分工怎麼調 | 她原本不會什麼、現在懂了什麼、想法怎麼轉彎 |
| 寫給誰 | 下一次的她 + 下一次的 AI | 未來回頭看的她 |
| 性質 | 可重複套用的**方法**（像球隊戰術筆記） | 不重複、只會累積的**軌跡**（像球員成長日記） |

**一句話判斷法**：寫完一句話，問「這句是在教下次怎麼做，還是在講她變成了什麼樣子？」
前者進 ④，後者進 ⑤。兩邊都塞得下的句子，通常是寫得太空泛，回去寫具體一點。

⑤ 只整理素材、**不要寫成完整日誌**。她已經有 `journal` skill 負責日誌的最終格式（五題引導 + 經她確認的 AI 協作觀察），這裡越俎代庖會讓她有兩套打架的日誌。

## 品質底線（交付前逐條檢查）

- 全形標點一致、沒有簡體字混入。
- 沒有 AI 腔：不用「總之」「綜上所述」開頭的段落，不用空泛口號當金句。
- 每個術語第一次出現時有一句白話解釋。
- ①②③ 的段落與時間互相對得上（簡報有的段落，教師手冊要有對應時間）。
- 痛點是具體場景，不是「不會用 AI」這種空話。
- 教師手冊的時間加總等於課程長度，而且**留 10% 緩衝**——現場一定會超時。
- 沒查證的內容標「待確認」，不要填一個看起來合理的假答案。

## 素材不足時怎麼辦

素材太薄（例如只有一頁大綱）撐不出五份產出時，**明說不足、指出缺什麼**，不要靠推測補滿。
可以問她：有沒有逐字稿、過去類似場次的講義、學員提問紀錄？
真的沒有就先產核心 + 簡報大綱，其餘標記「素材補齊後再產」。交一份誠實的半成品，好過交五份注水的完整品。

## 風格範本

`200_Reference/past-work/` 若有過去的教案，開工前先讀 2-3 份學她的用語與排版習慣。
目前這個資料夾可能是空的——這時就依本檔的規則寫，並在交付時提醒她：把這次的成品放進 `200_Reference/past-work/`，下次產出會更像她的手筆。
