## 一句話判讀

忠實度算法可借；與專家並用僅部分支持，「只作輔助」原文未說。

## 研究問題

忠實度怎麼定義與計算，如何搭配人工標註檢驗？

## 主要發現

與人工一致率：忠實度 0.95、答案相關性 0.78、脈絡相關性 0.70。

## 怎麼用進本研究

借逐條對照文件的忠實度算法，設計混淆矩陣的人工判定。（研讀建議，待老師判斷）
