CHAPTER 02

2. 範例一：半自動化客服資料庫（員工必用問答系統）

資料庫 ＝ 資料 ＋ 內部運作 SOP ＋ 外部回答 SOP ＋ 外部回答介面。

步驟這一步在做什麼你要做的事完成後的效果
Step 1 匯入資料建立知識底座將員工手冊、制度、SOP、常見 QA 上傳到 NotebookLM系統「有資料可查」，不再憑空回答
Step 2 建立 SOP規範怎麼回答設定讀取順序（手冊→QA→SOP）與無法回答就轉人工回答一致、不亂猜
Step 3 客服人設統一回答風格設定 AI 扮演「內部客服／HR 助理」，回答簡短、可條列員工看得懂、像在問櫃台
Step 4 歡迎訊息教員工怎麼用設定開場說明：能問什麼、不能問什麼降低亂問與學習成本
Step 5 分享設定控制權限決定是「只對話」或「對話＋可看資料」符合資安、好管理
Step 6 回饋迭代讓系統越來越準蒐集常見問題，定期更新文件與 QA問得越多，人力越省

優點與缺點一次看

類別說明
優點可快速回覆員工常見問題（請假、福利、流程），降低 HR 重複性工作負擔。
回答依據既有人資制度文件，提升回覆一致性與專業度。
新進 HR 或代理人可快速上手，減少制度學習時間。
回覆可附來源文件，提升透明度與信任感。
缺點若制度文件未即時更新，錯誤資訊可能被持續引用。
個案型、例外型問題（薪資、懲處）仍無法完全自動化。
需額外投入文件治理與維護成本（版本、權責、更新頻率）。

3. NotebookLM 資料表功能介紹（DATA TABLES）

2024 年 12 月 18 日全新推出。自動將零散的非結構化內容整理成清晰表格，開啟與 Apps Script 串接的無限可能。目前狀態：Pro 和 Ultra 用戶優先使用，免費用戶即將開放。

  • 一鍵生成結構化表格。
  • 智慧摘要與欄位萃取。
  • 可自訂提示詞指定欄位。
  • 直接匯出至 Google Sheets。

情境說明適用對象

CHAPTER 05

5. 範例二：NotebookLM × Sheets × GAS 一鍵化甘特圖（十一步驟）

階段工具操作重點目的與說明
1NotebookLM匯入原始資料（文件、表格、FAQ、SOP）將非結構化文字集中，作為後續結構化基礎
2NotebookLM使用「資料表」定義欄位（任務名稱、開始／結束日期、狀態）把文字轉為可運算的表格資料
3NotebookLM檢查日期格式與欄位一致性確保匯出後能被 Sheets 正確辨識
4Google Sheets將資料表匯入試算表作為視覺化與自動化的主要工作環境
5Google Sheets補齊分析用欄位（天數、開始偏移）把「實際日期」轉為「相對時間軸」，為甘特圖做準備
6Google Sheets驗證資料是否可手動畫出甘特圖確認資料結構正確
7Google Apps Script撰寫自動化流程（計算、清除舊圖、重建圖表）把多步驟手動操作整合為單一流程
8Google Apps Script建立自訂選單（如「甘特小幫手」）在試算表加入「像記帳小幫手」的功能入口
9Google Apps Script將核心流程綁定到選單功能使用者只需點一次即可完成所有更新
10使用者操作點選「一鍵生成／重畫甘特圖」真正的「一鍵化」，不需理解資料與技術細節
11教學與擴充延伸至多專案、狀態上色、權限控管升級為可教學、可制度化的應用案例

GAS 核心函式：一鍵重畫甘特圖（節錄）

Code.gsfunction redrawGanttChart() { const CONFIG = { SHEET_NAME: '會議交辦事項追蹤表', COL_TASK: '任務名稱', COL_START: '開始日期', COL_END: '結束日期', COL_DURATION: '天數', COL_OFFSET: '開始偏移', CHART_ANCHOR_ROW: 2, CHART_ANCHOR_COL: 1, REMOVE_ALL_CHARTS_ON_SHEET: true }; // 讀表頭 → 找必要欄位 → 取得/建立「天數」「開始偏移」欄 // 寫入公式：天數 = MAX(1, 結束日期 - 開始日期 + 1) // 寫入公式：開始偏移 = 開始日期 - 最早開始日 // 刪除舊圖表 → 建立堆疊長條圖（開始偏移設透明，天數顯示） // sheet.insertChart(chart); }
💡 完整程式碼含 buildColumnMap_、getOrCreateColumn_、getMinDate_、dateToSerial_ 等輔助函式，核心概念：系列1（開始偏移）設透明、系列2（天數）顯示，就能用堆疊長條圖模擬出甘特圖效果。
