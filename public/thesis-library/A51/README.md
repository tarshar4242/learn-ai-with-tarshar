## 研究問題

SECI 把外化當單一步驟太粗，外化該怎麼拆成可操作、可審查的步驟？

## 主要發現

拆成表達、結構化、鞏固三操作；訪談見做了什麼易、為什麼難；提六個待檢驗命題。
