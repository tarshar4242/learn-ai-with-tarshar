## 一句話判讀

召回率約 20% 為單一案件的抽樣估計，不能外推，也不能套用語意查找。

## 研究問題

大型全文檢索系統在真實訴訟中，能找回多少相關文件？

## 主要發現

精確率平均 79.0%，召回率平均 20.0%；律師卻自認超過 75%。

## 怎麼用進本研究

說明關鍵字查找的用詞落差，並提醒滿意度不等於真的找到。（研讀建議，待老師判斷）
