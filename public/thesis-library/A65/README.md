## 一句話判讀

完整參考資料得分最高，仍有錯誤；分數不是答題正確率。

## 研究問題

它評估回答正確性的做法，能怎麼用到本研究的兩種查找？

## 主要發現

完整資料人工評分51.74%，零樣本27.43%；錯誤分母須釐清。

## 怎麼用進本研究

將答案拆必要要素，分開評AI原始回答與受試者最終作答。（研讀建議，待老師判斷）

## 限制
