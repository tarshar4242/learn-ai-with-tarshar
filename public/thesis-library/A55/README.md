## 一句話判讀

題項與信效度完整公開，可當TAM題項範例；沒有滿意度構念，多處數字待核

## 研究問題

信任、應用程式設計、社會影響如何影響民眾接受政府AI聊天機器人

## 主要發現

社會影響到信任、易用性、有用性、態度、意圖一路成立；易用性對態度等三條不成立

## 怎麼用進本研究

易用性、有用性題可改寫成查找方式的評價題；前測做法可參考（研讀建議，待老師判斷）
