CHAPTER 02

2. NotebookLM 資料表：5+ 種實用情境

NotebookLM 專注於分析你上傳的文件，提供基於事實的回答，嚴格遵循來源資料、不瞎編亂造。資料表功能於 2024/12/18 推出，Pro／Ultra 用戶優先使用。

  1. 財務管理：將收據照片、銀行通知、訊息上傳，一鍵轉換為記帳表格（日期／項目／金額／分類）。
  2. 研究分析：彙整多篇論文，建立比較表（作者年份／研究方法／樣本數／主要發現／研究限制）。
  3. 競品分析：上傳競爭對手產品資訊，生成比較表（定價／目標客群／核心功能／優劣勢）。
  4. 會議管理：上傳會議逐字稿，萃取待辦事項表（任務／負責人／截止日／優先級）。
  5. 專案規劃：從討論紀錄自動生成任務分配表或簡易甘特圖資料（任務／負責人／開始日／完成日／相依任務）。
Prompt 範例（財務情境）
「請將這些消費紀錄整理成表格，欄位包含：日期、項目名稱、金額、消費分類（餐飲/交通/娛樂/日用品/其他）」
CHAPTER 03

3. 無「資料表」功能的替代方案

  1. 輸入提示詞：要求 NotebookLM 生成 Markdown 格式表格。
  2. 複製內容：複製生成的 Markdown 表格代碼。
  3. 貼上至 Sheets：直接貼上到 Google 試算表。
  4. 調整格式：簡單調整欄寬與框線即可使用。

4. Google Apps Script 基礎與自動分類

Google Apps Script 是基於 JavaScript 的雲端腳本平台：深度整合 Sheets／Gmail／Calendar／Drive，完全免費、雲端執行、使用廣泛流行的 JavaScript 語法。開啟方式：Google Sheets → 擴充功能 → Apps Script。

Code.gs 讀取／寫入function readData() { const sheet = SpreadsheetApp.getActive().getActiveSheet(); const data = sheet.getDataRange().getValues(); Logger.log(data); } function writeData() { const sheet = SpreadsheetApp.getActive().getActiveSheet(); sheet.getRange("A1").setValue("Hello"); sheet.appendRow(["2023/12/25", "午餐", 120]); }

範例一：自動分類帳目＋金額過高判斷

Code.gsfunction autoCategorizeAndCheckAmount() { const sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet(); const data = sheet.getDataRange().getValues(); const HIGH_AMOUNT_THRESHOLD = 500; const categoryRules = [ { keywords: ["Uber","捷運","公車","計程車"], category: "交通" }, { keywords: ["午餐","晚餐","早餐","便當"], category: "餐飲" }, { keywords: ["電影","KTV","遊戲"], category: "娛樂" }, { keywords: ["超市","家樂福","全聯"], category: "日用品" } ]; // D欄：依關鍵字自動分類；F欄：金額 > 500 標記「過高」，否則「正常」 }
CHAPTER 05

5. 範例二＋三：生成月度財務報表與自動繪製圖表

範例二：生成月度財務報表

運作邏輯：利用 JavaScript 物件作為雜湊表，將相同分類的金額累加，最後輸出至獨立報表頁面。

Code.gsfunction generateReport() { const sheet = SpreadsheetApp.getActive().getSheetByName("記帳"); const data = sheet.getDataRange().getValues(); const totals = {}; for (let i = 1; i < data.length; i++) { const category = data[i][3], amount = data[i][2]; if (category) totals[category] = (totals[category]||0) + amount; } const reportSheet = SpreadsheetApp.getActive().getSheetByName("報表"); reportSheet.clear(); reportSheet.appendRow(["分類","總金額"]); for (const cat in totals) reportSheet.appendRow([cat, totals[cat]]); }

範例三：自動繪製圓餅圖

繪圖流程：定義資料範圍 → 建立圖表物件 → 設定類型與位置 → 插入工作表。

Code.gsfunction createMonthlyExpensePieChart() { const sheet = SpreadsheetApp.getActiveSpreadsheet().getSheetByName("報表"); const lastRow = sheet.getLastRow(); const range = sheet.getRange(1, 1, lastRow, 2); const chart = sheet.newChart().asPieChart().addRange(range) .setOption("title", "本月支出分佈") .setOption("legend", { position: "right" }) .setPosition(2, 8, 0, 0).build(); sheet.insertChart(chart); }

7. 半自動化流程總覽與延伸應用

Phase 1：從零散筆記到結構化資料

  1. 資料搜集：消費收據照片、語音備忘錄、雜亂文字筆記。
  2. NotebookLM：上傳多種來源 → Data Table 處理 → Prompt 欄位定義。
  3. 結構化輸出：標準化表格 → 匯出 CSV → 匯入 Google Sheets。

Phase 2：從試算表到自動化報表

  1. Google Sheets：原始數據儲存 → 貼上 Markdown/CSV → 基礎格式調整。
  2. Apps Script：自動分類腳本 → 數據彙總邏輯 → 定時觸發執行。
  3. 自動化產出：視覺化圖表 → 月度財務報表 → Email 自動通知。

延伸應用

  • 專案管理：將會議錄音轉為待辦事項，自動同步至 Google Tasks 或 Trello。
  • 學術研究：整理大量文獻摘要，自動生成引用格式並匯入 Zotero 或 EndNote。
  • Line Notify 串接：將財務報表推送到 Line 群組，即時掌握資訊。
  • 行事曆整合：從筆記中識別日期與活動，自動建立 Google Calendar 行程。
  • AI 深度整合：分析長期消費數據，提供個人化省錢建議；打造個人知識庫第二大腦。
