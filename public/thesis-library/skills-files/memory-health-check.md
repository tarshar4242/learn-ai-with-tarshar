# AI 記憶系統健檢助手

你要替使用者檢查他的 AI Agent 記憶系統是否健康。

> **v1.1（2026-07-29）**：縮小預設掃描範圍，並把「只回報、不修改」設為預設。

核心觀念：記憶不是越多越好，而是要放在正確層級。

- L1：每次都必須看到，不看到就會出錯。
- L2：特定任務才需要，由 Skill 或工作流按需載入。
- L3：時序紀錄，事後回顧或搜尋時才需要。

## 健檢前提

只可從以下來源確認範圍：

- 目前已開啟的 workspace／專案根目錄。
- Pro-kit 01 已確認並留下紀錄的 Agent 母資料夾。
- 使用者這次明確指定的路徑。

先把準備檢查的完整路徑告訴使用者。不要憑猜測掃整台電腦，也不要把整個家目錄或 `~/Documents` 當候選範圍。

## 寫入邊界

預設只讀取與回報：

- 不修改 `AGENTS.md`、`CLAUDE.md` 或任何記憶檔。
- 不搬移、刪除、合併或重新命名檔案。
- 不自行建立報告。

只有使用者看過建議並明確同意某一項寫入後，才可執行那一項；不要把「幫我健檢」解讀成「直接幫我整理」。

## 健檢範圍

優先檢查：

- 根目錄規則檔：`AGENTS.md`、`CLAUDE.md`、`GEMINI.md`、`.cursorrules`。
- L2：先讀 Pro-kit 01 留下的 `SKILLS_DIR`，再檢查該唯一原始資料夾與全域入口 `~/.claude/skills/`、`~/.agents/skills/`。專案裡的 `.claude/skills/`、`.agents/skills/` 若有內容，確認那是該 repo 專屬 Skill，不是個人 Skills 被重複掛了一份。
- L3：`000_Agent/memory/`、`000_Agent/memory/daily/`、`300_Journal/` 或使用者實際日誌資料夾。
- 最近的作品或工作流候選：`100_Todo/`、`000_Agent/skills/_candidates/`。

## 流程

### Step 1：盤點

列出實際存在的記憶結構：

| 層級 | 目前位置 | 狀態 |
|---|---|---|
| L1 |  | 有 / 沒有 / 過肥 |
| L2 |  | 有 / 沒有 / 觸發不清 |
| L3 |  | 有 / 沒有 / 找不到脈絡 |

### Step 2：檢查 L1

判斷根規則是否：

- 短、硬、每次都需要。
- 避免塞長 SOP、歷史紀錄、整份專案清單。
- 有清楚的安全邊界。
- 有路徑與語言規則。

如果 L1 太肥，提出搬移建議：

- 任務流程搬到 L2 Skill。
- 歷史案例搬到 L3 memory。
- 專案清單搬到 knowledge 索引。

### Step 3：檢查 L2 Skill

抽查 3～8 個 Skill，重點看：

- description 是否清楚寫出觸發情境。
- 是否太泛，例如「處理所有事情」。
- 是否有明確輸入、輸出、停止條件。
- 是否可以被未來的 AI 直接使用。

把問題分成：

- 應該改 description。
- 應該拆成多個 Skill。
- 應該降級成 checklist 或 SOP。
- 應該刪除或封存。

### Step 4：檢查 L3 時序紀錄

確認是否能回答：

- 最近一週做了什麼？
- 最近踩過什麼坑？
- 使用者糾正過 AI 哪些偏好？
- 有沒有重要決策紀錄？

如果只有流水帳，建議改成「每日摘要 + 決策 + 待沉澱規則」格式。

### Step 5：找重複錯誤

搜尋或詢問使用者：

- 最近 AI 重複犯過什麼錯？
- 哪些規則每次都要重講？
- 哪些任務每次都從零開始？

判斷這些應該沉澱到哪一層。

### Step 6：輸出報告

報告格式：

```markdown
# AI 記憶系統健檢報告

## 總結

## 目前結構

## 健康的地方

## 需要修正的地方

## L1 建議

## L2 Skill 建議

## L3 日誌建議

## 下週只做三件事

## 不建議做的事
```

若使用者看過對話報告後明確要求保存，優先寫到：

- `000_Agent/reports/YYYY-MM-DD-memory-health-check.md`
- 或使用者指定的位置。

寫檔前確認資料夾存在，不覆蓋既有檔案。使用者只同意保存報告，不代表同意執行報告裡的修改建議。

## 判斷標準

健康的 AI Agent 不一定記很多，但應該：

- 每次都能讀到最重要規則。
- 需要任務能力時找得到 Skill。
- 最近脈絡能從日誌找回來。
- 重複錯誤會變成規則或流程。
- 不把所有東西塞進 L1。
