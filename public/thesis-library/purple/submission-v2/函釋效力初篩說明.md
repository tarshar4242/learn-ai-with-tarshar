# E2：函釋效力初篩與查證限制

查核日：2026-10-26。執行者：Codex AI。這是逐筆要旨初篩、部分官方原文查證與工程欄位建置，**不是 138 筆函釋的人類專業核定**。資料仍不能被稱為「已完成現行效力審查」。

## 完成與尚未完成

- 1,781 筆文件均有 `status`、`effective_from`、`superseded_by`。未查明者用 `null` 或「版本待查」，沒有用發文日期冒充施行日期。
- 狀態分布：有效 0、停止適用 0、前提法條已刪除 3、版本待查 1,778。138 筆函釋中，前提法條已刪除 3、版本待查 135。
- 每筆函釋都保留文號、日期、風險標記與初篩說明。重點文件增加個別理由與來源。未發現明顯問題不代表仍有效。
- 沒有刪除、過濾文件或改變 A 組字面查找定義；效力欄位需由整合端同時提供給兩組使用者，並送入 B 組 evidence。
- 135 筆函釋之現行適用性尚待領域評閱；另外 3 筆也只是已確認前提條文刪除，不等於完整判定函釋整體效力。

## 官方查證帶來的三個重要修正

**刪除公布日與施行日不同。** FINT-97、98、108 都依據性別工作平等法第 22 條但書。[全國法規資料庫沿革](https://law.moj.gov.tw/LawClass/LawHistory.aspx?pcode=N0030014)確認 2022-01-12 公布刪除，行政院 2022-01-17 令定 2022-01-18 施行。因此 `status_effective_from` 為 2022-01-18，`premise_change_promulgated_on` 為 2022-01-12。原函本身 `effective_from` 不受這兩個日期冒填。

**停止適用公告與其停止的文件不同。** FINT-42、62、65、96、111 本身是公告其他函釋停止適用的文件，不能因包含「停止適用」就把公告本身標成停止適用。已逐一核對官方全文並另列對象。FINT-62 全文列 6 函，其中庫內 FINT-66、69 的「與勞工職業災害保險及保護法規定未合部分」自 2022-05-01 停止適用。這是部分效力問題；尚未逐句判定衝突範圍，因此兩筆仍標「版本待查」，加上明確警示與 FINT-62 連結。停止對象其他文號未精確比對到庫內文件，不擅自建立關係。

**搜尋結果順序網址確實會漂移。** 本輪下載 FINT-108、93 的官方搜尋索引所提供舊 `recordno` 網址，HTTP 200 但文號已變成其他文件；搜尋引擎的快取摘要仍顯示原文號。這兩份錯配 HTML 留存為反例並標 `not_supporting_evidence=true`，不拿來支持原函效力。重新以精確文號搜尋取得正確頁面，核對文號後留存。新的網址仍是查詢式網址，不能宣稱永久固定連結。

## 檔案與重跑

- `document-metadata.json`：1,781 筆候選欄位，供整合入共同語料。
- `interpretation-review.csv`：138 筆函釋初篩表，方便人類逐筆續查。
- `verified-findings.json`：個別判定、官方網址、來源取得方式與限制。
- `source-snapshots.json`、`exact-number-snapshots.json`：官方原頁 SHA256、下載資訊與文號比對。`source-snapshots/` 存 HTML 與原函影本；錯配頁另外標記，不能當佐證。
- `scripts/annotate_validity.py`：由指定語料與固定證據檔重建 metadata 和 CSV，不直接覆寫 corpus。
- `tests/test_validity_metadata.py`：9 項測試，包括公告／對象區分、公布／施行日期、未知不冒稱有效、來源雜湊、錯配頁不得支持判定。

```sh
python scripts/annotate_validity.py --corpus data/corpus.json \
  --evidence data/validity/verified-findings.json \
  --output data/validity/document-metadata.json
python -m pytest -q tests/test_validity_metadata.py
```

本次以舊語料產生的候選 metadata SHA256：`3fe1e172229ed2ba04b1cf926e824658ebafd0d3b791edbd413b942b70cf593b`。證據檔 SHA256：`9b0dd9fb25a5b886b134ca8fa2da0027fde3bc9688384605204147a6a253393e`。整合新語料後重跑會更新來源語料雜湊；不得把新舊雜湊混為同一版。

E2 工程欄位與可追溯初篩已備妥；138 筆的人工法律效力核定仍未完成，不能用這一份初篩解除正式實驗的全部語料效力阻斷。
