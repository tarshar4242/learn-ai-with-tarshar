## 一句話判讀

可作理論背景，不能當證據；原文未談關鍵字或語意查找。

## 研究問題

若從使用者的異常知識狀態出發，資訊檢索該如何設計與評估？

## 主要發現

需求說不清楚時，最佳匹配不適合；對指明得清楚的需求，最佳匹配仍是候選。

## 怎麼用進本研究

作比較關鍵字與語意查找的理論背景，說明題目情境卡的設計精神。（研讀建議，待老師判斷）
